# Signal Processing & Machine Learning Lab

This repository contains professional implementations of various signal processing and machine learning experiments.

**Author:** Bagada Vishal Jayantilal

## Experiments Overview

| Experiment | Description | Folder |
|------------|-------------|--------|
| Spectral Density Analysis | Analysis of signal spectra and power spectral density. | [`spectral-density-analysis`](./spectral-density-analysis) |
| Image Filtering | Implementation of 2D signal filtering and image processing operations. | [`image-filtering-2d-signals`](./image-filtering-2d-signals) |
| RLS Speech Denoising | Speech noise reduction using the Recursive Least Squares (RLS) algorithm. | [`rls-speech-denoising`](./rls-speech-denoising) |
| Bearing Fault Diagnosis | Machine learning approach to diagnose faults in rolling element bearings. | [`bearing-fault-diagnosis`](./bearing-fault-diagnosis) |
| Heart Sound Classification | Analysis and classification of heart sound signals. | [`heart-sound-classification`](./heart-sound-classification) |
| SVD Image Compression | Image compression using Singular Value Decomposition (SVD). | [`svd-image-compression`](./svd-image-compression) |

## Structure
Each experiment is organized into:
- `src/`: Contains the source code (Python scripts and Jupyter notebooks).
- `results/`: Contains output data, plots, and sample datasets.
- `README.md`: Detailed explanation of the experiment.
